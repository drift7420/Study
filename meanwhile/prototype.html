Meanwhile

Pick a moment and see the whole world at once. Drag the slider — the scale is variable-rate, so the deep past moves in centuries and recent history moves year by year. Tap the coloured dots to filter by type, and any entry to open its detail screen. Every entry is real historical data.

Year header Shows “c.” when the slider’s step is coarser than the data’s precision — no false exactness. ≈ 110dp with chips
Era chips Span-based labels, not “Medieval / Renaissance”. Jumps to the start of an era; highlights to track the slider.
World map Whole globe, cropped 60°S–80°N. Fits in a fifth of the screen — nothing to pan or pinch. 358 × 138dp

Locked so far

  • Wikidata snapshot → bundled SQLite, lean tier ≈ 20MB
  • Normalised persons / polities / events
  • Signed integer years + precision flag
  • active_start/active_end for querying, real dates for display
  • notability from sitelink count drives ranking
  • Nullable wiki_title — falls back to name
  • No network in v1: detail screens are local, Wikipedia is a handoff

This screen’s queries

  • Year view: three-way UNION over (active_start, active_end, region_id, notability)
  • Overlap is against the step window — start < year + step — so at 10yr resolution the screen shows the decade, and single-year events can’t fall through the gaps
  • Contemporaries: interval overlap with the +15 adult rule
  • Regions in fixed dawn order (longitude descending from the date line) — never re-ranked, so scrubbing shows change rather than reshuffling

Still open

  • The ETL pipeline that builds the database — the real risk
  • How the design holds up against 50k messy real rows
  • Whether the coarse buckets show too much at once
  • Android project structure (after the data is proven)

On the map: it’s a schematic dot-grid, not a basemap — rendered from polygons on a Compose Canvas in the real thing, so it works fully offline with no map SDK or API key. Markers sit at region centroids, so it reads density and spread rather than exact position. “Meanwhile” is a placeholder name — it just fit the idea of cutting away to what else was happening.
